# Docs site

Docusaurus docs for **Firebase Email Link Host** and **[app-universal-links-helper](https://github.com/rutvik24/app-universal-links-helper)**.

Always use **Bun**:

```bash
bun install
bun start          # local
bun run build      # → build/ (GitHub Pages)
```

From the repo root:

```bash
bun run docs:dev
bun run docs:build
```
