# Docs site

Docusaurus docs for **Email Link Host** and **[App Universal Links Helper](https://rutvik24.github.io/app-universal-links-helper/)**.

Always use **Bun**:

```bash
bun install
bun start          # local
bun run build      # → build/ (GitHub Pages)
```

From the repo root:

```bash
bun run docs:dev
bun run docs:build
```
